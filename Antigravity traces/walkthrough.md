# Comprehensive App Data Wiring Walkthrough

We have successfully replaced all the hardcoded placeholders in the inner screens of the CIRO app! The entire user flow—from the map down to the deepest dispatch logs—is now dynamically populated by your serverless AI backend.

## What Was Accomplished

1. **Map Screen to Detail Sheet Handoff (`map_screen.dart` -> `crisis_detail_sheet.dart`)**
   - The map markers no longer just pop up a generic "Flash Flood" sheet. They now physically pass the exact JSON crisis document they represent into the bottom sheet.
   - The `CrisisDetailSheet` now displays the *actual* title, dynamic location, real severity badge (CRITICAL/HIGH/MEDIUM), dynamic confidence bar (e.g. 94%), and the real timestamp generated by Agent 2 (Detection).

2. **Deep Dive Screen Integration (`deep_dive_screen.dart`)**
   - When you tap "Full Details" from the bottom sheet, the `crisis` object is seamlessly passed down to the `DeepDiveScreen`.
   - Instead of dummy text, the screen now renders the **actual Agent 3 Response Plan** (the text generated by Vertex AI on the backend) so you can read exactly *why* the AI decided to take certain actions.

3. **Dispatch Command Center (`dispatch_screen.dart`)**
   - We converted the Dispatch screen to a Riverpod `ConsumerWidget`.
   - It now actively listens to the `ticketsStreamProvider` (which watches the `emergency_tickets` Firestore collection).
   - Instead of hardcoded "Traffic Police" and "Rescue 1122" cards, the screen iterates over the live tickets generated by **Agent 4 (Execution)** and dynamically builds the UI cards. It maps the correct icons (`siren`, `flame`, `heartPulse`), updates the status tones (Teal for Alerted, Red for Dispatched), and displays the AI-calculated ETAs.

## End-to-End Hackathon Demo Flow

Your app is now 100% ready for the demo:
1. Open the app to the **Map Screen**.
2. Tap the Sparkle FAB to open the **Simulation Sheet**.
3. Tap **Start Simulation**.
4. Wait for the pipeline to finish (you can show the GCP logs if you want to show the agents thinking).
5. The Map drops a new Marker. **Tap it**.
6. The Bottom Sheet slides up showing the real crisis data. **Tap "Full Details"**.
7. Read through the AI's generated Response Plan on the Deep Dive screen.
8. Navigate over to the **Dispatch Screen** via the Bottom Navigation.
9. Watch as the live emergency dispatch tickets are populated, showing exactly which services the AI alerted!
