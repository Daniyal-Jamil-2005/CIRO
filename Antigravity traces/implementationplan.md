# Full App Data Wiring Implementation Plan

The Map and Feed screens are now fully functioning with live data. However, as requested, we need to completely rip out the hardcoded mock data from the remaining detail screens (`Dispatch`, `Crisis Detail Sheet`, and `Deep Dive`) to ensure the entire app functions flawlessly with the simulated live data.

## Proposed Changes

### [MODIFY] `lib/ui/screens/map_screen.dart`
- Currently, tapping a marker opens the Crisis Detail Sheet but doesn't pass any data. We will update the `onTap` handler for the `GoogleMap` markers to pass the specific crisis object from the stream into the `CrisisDetailSheet`.

### [MODIFY] `lib/ui/screens/crisis_detail_sheet.dart`
- Update the widget to accept a `Map<String, dynamic> crisis` parameter.
- Replace the hardcoded "Flash Flood, Gulberg" data with dynamic bindings:
  - Title & Location: `crisis['title']` and `crisis['location']`.
  - Severity: `crisis['severity']`.
  - Confidence Bar: `crisis['confidence_score']`.
  - Signals Count: `crisis['signals_count']`.
  - Pass the crisis object downstream to the `DeepDiveScreen`.

### [MODIFY] `lib/ui/screens/deep_dive_screen.dart`
- Update the widget to accept the `crisis` parameter.
- Replace the hardcoded Agent Reasoning and Impact text with the dynamic `crisis['response_plan']` generated by Vertex AI (Agent 3).

### [MODIFY] `lib/ui/screens/dispatch_screen.dart`
- Convert from `StatelessWidget` to a `ConsumerWidget`.
- Connect the screen to the existing `ticketsStreamProvider`.
- Replace the hardcoded dispatch cards (Traffic Police, Rescue 1122) with dynamic cards generated from the real `emergency_tickets` collection populated by Agent 4. The screen will dynamically list out the service, action, status, and ETA.

## Verification Plan

### Manual Verification
1. Run the Flutter app and trigger a simulation via the Map Screen.
2. Wait for the marker to appear, then tap it.
3. Verify that the bottom sheet shows the dynamically generated title (e.g., "FLOOD - Karachi") and the correct severity/confidence.
4. Tap "Full Details" to open the Deep Dive screen and verify the AI-generated `response_plan` is visible.
5. Navigate to the **Dispatch Screen** (via bottom nav or "More" tab) and verify the live emergency tickets (e.g., "Dispatched Fire Brigade") populate the list automatically.
